Beginner's Guide to GitHub
=========================

What is GitHub?
---------------
GitHub is a website that stores your code online. It lets you
keep track of changes, share projects, and host simple websites
for free.


Key Terms
---------
- Repository (repo): A folder for your project on GitHub
- Branch: A separate version of your code (like a draft)
- Main branch: The "official" version of your code
- Commit: A saved snapshot of your changes
- Merge: Combining a branch back into main
- Pull Request (PR): A request to merge a branch into main
- GitHub Pages: Free website hosting from your repo


How to Create a Repository
--------------------------
  1. Go to github.com and sign in (or sign up)
  2. Click the "+" button in the top right corner
  3. Click "New repository"
  4. Give it a name (e.g. "my-project")
  5. Choose Public or Private
  6. Click "Create repository"


How to Get Your Repo On Your Computer
-------------------------------------
  1. Install Git on your computer
     - Mac: open Terminal, type "git" and follow the prompts
     - Windows: download Git from git-scm.com
  2. Open your terminal (Mac) or Git Bash (Windows)
  3. Type: git clone https://github.com/YOUR-USERNAME/YOUR-REPO.git
  4. This downloads the repo to your computer


How to Save and Upload Changes
------------------------------
  1. Make your changes to the files
  2. Open terminal in your project folder
  3. Type these commands:
     git add .
     git commit -m "describe what you changed"
     git push
  4. Your changes are now on GitHub


How to Merge a Branch
---------------------
  1. Go to your repo on github.com
  2. If you see a banner about recent pushes, click
     "Compare & pull request"
  3. Click "Create pull request"
  4. Click "Merge pull request"
  5. Click "Confirm merge"
  6. Your branch is now part of main


How to Host a Website with GitHub Pages
---------------------------------------
  1. Go to your repo on github.com
  2. Click Settings (top menu)
  3. In the left sidebar, click Pages
  4. Under "Source", select "Deploy from a branch"
  5. Pick the main branch, / (root) folder
  6. Click Save
  7. Wait 1-2 minutes
  8. Your site will be live at:
     https://YOUR-USERNAME.github.io/YOUR-REPO-NAME/


How to Install a Website as a Phone App
---------------------------------------
  1. Open the website URL on your phone's browser
  2. iPhone: tap the Share button (square with arrow)
     > "Add to Home Screen"
  3. Android: tap the 3-dot menu > "Install app"
     or "Add to Home Screen"
  4. It now appears on your home screen like a real app
     (only works if the site has PWA support)
